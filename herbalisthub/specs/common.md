# HerbalistHub - Common Specification

## Project Overview
**Project Name:** HerbalistHub  
**Tech Stack:** Next.js 14 + TypeScript + Prisma + MySQL + Tailwind CSS + shadcn/ui

**Purpose:** Comprehensive web application for herbalists to manage practice, track inventory, engage with clients, and share knowledge.

**Target Users:**
- Primary: Professional herbalists and herbal practitioners
- Secondary: Clients seeking herbal consultations  
- Tertiary: General public interested in herbal information

## Core Features
1. **Inventory Management** - Track herbs, preparations, expiration dates
2. **Client Management** - Intake forms, appointments, messaging, history
3. **Formula Builder** - Create/save formulas, cost calculation, versioning
4. **Public Content** - Blog, events, photo gallery, newsletters
5. **Authentication** - Multi-provider auth, role-based access (Admin/Client/Public)

## User Stories
### As Herbalist Admin:
- Track herb inventory and prevent stockouts
- Create custom intake forms for client information
- Schedule appointments with Google Calendar sync
- Publish educational blog posts and formulas
- Track client treatment histories
- Calculate costs and set pricing

### As Client:
- Book appointments online
- Fill intake forms before consultation
- Message herbalist securely
- Access treatment history and recommendations
- Participate in community discussions

### As Public User:
- Read educational blog posts
- View published formulas and recipes
- Register for events and workshops
- Sign up for newsletters
- Engage in community discussions
